# Автоматизированный конвертер DTO (Go → Rust) для Incus

Данный проект представляет собой систему для автоматической синхронизации моделей данных между сервером **Incus** (Golang) и клиентскими приложениями (Rust).

## Архитектура репозитория

Проект состоит из двух независимых компонентов:

1. **`/generator` (Трансформатор)**
   - Написан на Python + Go.
   - Использует встроенный пакет `go/ast` для точного синтаксического разбора исходников Incus.
   - Транслирует Go-типы (struct, enum, alias, tags) в семантически корректный Rust-код (с поддержкой `serde` и модульной системы).
   - Включает валидатор, который "на лету" проверяет сгенерированный код через `cargo check`.

2. **`/client` (Потребитель / Proof of Concept)**
   - CLI-приложение `incus-lab-manager` на Rust.
   - Выступает в роли Infrastructure as Code (IaC) утилиты.
   - Интегрирует автосгенерированные DTO (`client/src/incus/`) для формирования валидных JSON-запросов к API.
   - Позволяет разворачивать виртуальные сети и контейнеры в Incus на основе YAML-конфигураций по защищенному mTLS каналу.

## 🚀 Как это работает
1. Скачивается актуальный исходный код Incus.
2. Запускается пайплайн генератора: `Парсинг -> Генерация -> Валидация -> Сохранение`.
3. Сгенерированные файлы (`*.rs`, `mod.rs`) автоматически обновляют библиотеку клиента.
4. Клиент компилируется со свежими моделями и готов к отправке API-запросов.
